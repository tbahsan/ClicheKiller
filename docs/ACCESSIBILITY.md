# ClicheKiller — Accessibility (a11y) Conformance

## Conformance Standards (WCAG 2.1 AA)
1. **Semantic HTML:** Fully native `<header>`, `<main>`, `<aside>`, `<section>`, `<footer>`, `<button>`, and `<textarea>`.
2. **Keyboard Accessible:** All action buttons, filter checkboxes, and alternative replacement pills are operable via `Tab` and `Enter`/`Space`.
3. **Contrast Ratios:**
   - Dark theme `#020617` vs text `#f8fafc`: Contrast ratio > 16:1.
   - Light theme `#f8fafc` vs text `#0f172a`: Contrast ratio > 16:1.
   - Category tags use colored bottom borders in addition to background tints to avoid relying solely on color hue.
